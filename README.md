# Лев-скрипт

Защото лева може вече да е изчезнал като валута, но не е изчезнал от моето сърце.

Наръчникът описващ синтаксиса и стандартната библиотека на езика се намира
[тук](https://momchil_kalestrov.gitlab.io/lev-script-docs/).

За да се компилира проекта трябва да се екзекутира `build` чрез `npm`, `pnpm`
или `yarn`. Това ще създаде фаил в `dist/` наиме `interpreter.exe` при Windows и
`interpreter` за Linux и POSIX среди.

# Lev-script

Because the lev may be gone as our currency, but it's not gone from my heart.

The documentation defining the syntax and standard library can be found
[here](https://momchil_kalestrov.gitlab.io/lev-script-docs/en/).

To build, run the `build` script via `npm`, `pnpm`, `yarn` or the pm of your
choosing. This will output a file in `dist/` named `interpreter.exe` on Windows
and `interpreter` for Linux/ POSIX environments.
