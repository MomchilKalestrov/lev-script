# Console

## Functions

### Log

`(str: string): null` - Writes the value of `str` to `stdout`.

### Error

`(str: string): null` - Writes the value of `str` to `stderr`.

### ReadLine

`(): string` - Reads a line from `stdin`.

# Parse

## Functions

### ToNumber

`(str: string): number` - Converts `str` into a numeric value. Throws if it
cannot.

### ToBoolean

`(str: string): number` - Converts `str` to a boolean value.
