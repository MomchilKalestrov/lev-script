# Синтаксис

## Променливи

Дефиниране:
```lv
var <име>: <тип> = <начална_стойност>;
```

Променливите **не могат** да се дефинират без начална стойност.

Присвояване на стойност:
```lv
<име> = <стойност>;
```

Стойността трябва да е от същия тип като зададения при дефинирането на променливата `<тип>`.

Няма начин няколко променливи да се инициализират едновременно:
```lv
var <име>: <тип>, <име>: <тип>... # невалидно!
```

## Функции

Дефиниране:
```lv
fn <име> = (<име>: <тип>): <тип_на_връщаната_стойност> => {
    # ...
};
```

Функциите могат да се претоварват чрез повторно дефиниране на функцията със списък от аргументи, който е различен:
```lv
fn <име> = (): <тип_на_връщаната_стойност> => {
    # ...
};

fn <име> = (<име>: <тип>): <тип_на_връщаната_стойност> => {
    # ...
};

<име>(); # валидно, извиква първата функция
<име>(<аргумент>); # също е валидно, извиква втората функция
```

Парсерът *технически* позволява скобите да бъдат пропуснати, подобно на стрелковите функции в TypeScript, **но** функцията **няма** да върне стойността на следващия израз — за това все още е необходим оператор `return`:
```lv
# технически е валидно, но **няма** да върне получената стойност
fn <име> = (): <тип_на_връщаната_стойност> => <произволен оператор или израз>;
```
```lv
# също е валидно и **ще** върне получената стойност
fn <име> = (): <тип_на_връщаната_стойност> => return <израз>;
```

Това се счита за антипатърн и трябва да се избягва.

Използването на `AssingmentExpression` върху функция (т.е. `функция = <нова функция>`) е невалидно.
```lv
fn Func = (): null => {};

Func = (): boolean => { # невалидно!
    return true;
};
```

Добавянето на претоварвания към функционален аргумент вътре в извикване важи само в рамките на това извикване. Новите претоварвания могат да се използват там, но не засягат оригиналната функция извън него:
```lv
fn Func = (): null => {};

fn ModifyFunc = (F: function): boolean => {
    fn F = (a: number): null => {};

    F(); # валидно
    F(1); # валидно
};

ModifyFunc(Func);
Func(1); # невалидно
```

## Условни конструкции

Засега се поддържат само `if`/`else` и `while`:

```lv
if (a == b) {
    # извършване на действие
}
```
```lv
var c: number = 0;
while (c < 10) {
    c = c + 1;
}
```

Както при функциите, скобите могат да бъдат пропуснати:
```lv
var c: number = 0;
while (c < 10) c = c + 1;
```

Това е предвидено поведение.

## Обекти

В lev-script **няма анонимни обекти**.
```lv
# невалидно!
var obj: Object = {
    #...
};
```

Обектите са свързани с определен тип:
```lv
type Person = {
    var name: string = "Miroslav";

    fn Present = (): null => {
        console.log("Здравей, аз съм " + this.name);
    };
};
```

lev-script **не е ООП език**. Типовете му нямат необходимите характеристики, като например наследяване, полиморфизъм и модификатори за достъп. Това означава, че всички членове на даден тип са публични.

Свойствата и функциите, дефинирани в даден тип, могат да бъдат достъпвани чрез екземпляр на този тип с помощта на ключовата дума `this`. Тя е константа, което означава, че не може да ѝ се присвоява нова стойност и не могат да се добавят нови свойства към нея.

Операторът `type` може да се използва само на най-горно ниво, т.е. не може да се включва например в тялото на функция.

### Оператори

Забележка — имената на функциите, изброени по-долу, **не са окончателни** и може да се променят в бъдеща версия.

Следните оператори могат да бъдат претоварени чрез включване на функция със съответното име на оператора:

| Оператор | Име |
|---|---|
| `+` | `__add__` |
| `-` | `__sub__` |
| `*` | `__mul__` |
| `/` | `__div__` |
| `%` | `__mod__` |
| `==` | `__eq__` |
| `!=` | `__neq__` |
| `<` | `__lt__` |
| `>` | `__gt__` |
| `<=` | `__lte__` |
| `>=` | `__gte__` |
| `<<` | `__shl__` |
| `>>` | `__shr__` |
| `&` | `__band__` |
| `\|` | `__bor__` |
| `^` | `__xor__` |

Например, за да претоварите оператора `==` между два обекта от тип `Person`:
```lv
type Person = {
    # ...

    fn __eq__ = (person: Person): boolean => {
        return this.name == person.name;
    };
};

# ...

if (person1 == person2) {
    # валидно, тъй като `Person` има функция `__eq__` за стойности от тип
    # `Person`
}

if (person1 == 1) {
    # невалидно, тъй като `Person` няма функция `__eq__` за стойности от тип
    # `number`
}
```

Първо се изпълнява претоварването на оператора от левия операнд. Ако няма подходящо претоварване, се изпълнява претоварването на оператора от десния операнд.

Следните оператори изискват функция **без аргументи**:

| Оператор | Име |
|---|---|
| `!` | `__not__` |
| `-` | `__neg__` |

```lv
type Person = {
    # ...

    fn __not__ = (): boolean => {
        return !this.name;
    };
};
```

Макар да е разумно да се очаква определени типове стойности да бъдат връщани (например извикване на `__eq__` да връща `boolean`), това не е задължително. Всички оператори могат да връщат стойности от произволен тип.

### Индексиране

Типовете могат да реализират индексиране чрез специалните функции `__index__` за получаване на стойност и `__index_set__` за задаване на стойност.

`__index__` приема само един аргумент — индекса (стойността между квадратните скоби). Функцията може да бъде претоварена, за да приема различни типове индекси, например низове *и* числа.
```lv
type KeyVal = {
    # ...
    fn __index__ = (key: string): string => {
        # ...
    };

    fn __index__ = (key: number): string => {
        # ...
    };
};

console.log(keyval[ "key" ]);
```

`__index_set__` има същия първи аргумент като `__index__`, но приема и втори аргумент. Вторият аргумент също може да бъде претоварен.
```lv
type KeyVal = {
    # ...
    fn __index_set__ = (key: string, value: number): null => {
        # ...
    };

    fn __index_set__ = (key: string, value: string): null => {
        # ...
    };
};

keyval[ "key" ] = "value";
```

## Импортиране на други модули

Операторът `import` позволява импортиране на други модули. При използването му всички декларации в модула се включват в текущия модул:

```lv
import "<път>";
```

Например:

```lv
# file1.lv
fn Add = (a: number, b: number): number => {
    return a + b;
};
```

```lv
# file2.lv
import "./file1.lv";

Console.Log(add(1, 1));
```

Пътищата до модулите се разрешават спрямо пътя до модула, в който се намира операторът `import`.
