# Console

## Функции

### Log

`(str: string): null` — Извежда стойността на `str` на стандартния изход (`stdout`).

### Error

`(str: string): null` — Извежда стойността на `str` на стандартния поток за грешки (`stderr`).

### ReadLine

`(): string` — Прочита един ред от стандартния вход (`stdin`).
